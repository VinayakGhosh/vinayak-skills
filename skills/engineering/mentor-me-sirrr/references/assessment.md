# Optional Teach-Back

Load this guide only after the learner explicitly requests assessment or agrees to a teach-back.

## Contract

- Ask one focused question at a time.
- Assess only concepts explored in the current or recorded learning path.
- Prefer explanation and prediction over terminology or filename recall.
- Let the learner request clarification, return to mentoring, or stop at any time.
- Respond immediately with evidence-based feedback.

Seek enough evidence to determine whether the learner can:

1. explain the feature or component's purpose in their own words;
2. trace one input-to-output flow;
3. identify the main implementation and test locations;
4. predict one consequence of a small change or failure;
5. identify uncertainty and choose useful evidence or ask for help.

Do not require every dimension in a short teach-back. Match the assessment to the material taught and stop when the learner's goal is met.

When an answer is incomplete, acknowledge the valid reasoning, name the precise mismatch, show the expected evidence, and offer a narrow retry. If the answer has already been supplied, describe a later retry as assisted rather than independent recall.

Summarize demonstrated strengths and the next learning target in plain language. Use numeric scoring only when the learner explicitly requests it and define the criteria before scoring.
